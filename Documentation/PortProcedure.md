# How to port to other FPGA, ASIC and SoC

This procedure is now part of the Getting Started guide, under
**[Porting ztachip to Other FPGAs, ASICs, and SoCs](https://ztachip.github.io/GettingStarted.html#4-porting-ztachip-to-other-fpgas-asics-and-socs)**.

It covers what to change in the hardware stack — the platform configuration, the
wrapper library and the top-level component — and in the software stack: core
count, linker file, boot loader and peripheral drivers.
